# 마음침 이해통찰 과정 (안내형 시제품)

`index.html`을 브라우저에서 열면 ① 신념 설명과 83문항 검사 ② 거사 ③ 양정 순서로 진행할 수 있습니다. 검사 없이 거사부터 시작할 수도 있습니다. 세 페이지는 별도 빌드나 API 키 없이 작동합니다. 검사 그래프는 CDN의 Chart.js가 열리지 않으면 생략되고 영역별 표는 계속 표시됩니다.

- 검사 문항과 역채점 및 10개 하위영역은 제공된 「비합리적 신념검사(83문항).pdf」를 기준으로 유지했습니다. 첨부 채점표에는 40번 문항이 빠져 있으나, 동일한 83문항을 사용한 심지연(2010)의 학위논문 <표 III-2>에서 **파국화의 40번 역채점 문항**임을 확인하여 파국화에 포함했습니다. 또한 첨부본 채점표에서 70번은 역채점으로 표기되어 있어 이를 적용했습니다. 문항 목록과 채점표 사이의 별표 표기가 일치하지 않는 곳에는 채점표를 우선했습니다. 해당 논문은 일부 다른 문항의 역채점 표기가 첨부본과 달라, 이번 확인을 근거로 첨부본의 다른 문항 채점까지 임의로 바꾸지는 않았습니다.
- 첫 화면의 12가지 설명은 제공된 「비합리적인 신념 12가지 (1).pdf」의 요약입니다. 검사 10개 영역과 일대일 매핑하지 않습니다.
- 거사와 양정은 제공된 「실습보조교재_260915.pdf」 및 「이해통찰과정 질문목록.pdf」의 질문 흐름을 참고해 단계별로 구성했습니다. 현재 분기는 선택지와 일부 응답 표현에 따른 안내 문구이며, 자유 서술 답변을 AI가 이해하거나 분석하지 않습니다. 진행자용 임상 판단과 구체적인 경혈·정심주 절차는 구현하지 않았습니다.
- 양정의 긍정 취상 단계에서는 작성한 문장에 포함된 명시적인 단어(바다, 나무, 산, 햇살 등)를 기본 장면 선택에만 사용합니다. 사용자가 장면과 색감을 바꾸어 추상적인 SVG 취상 카드를 만들고 저장할 수 있습니다. 이는 글을 사실적으로 해석해 생성하는 AI 이미지가 아닙니다.
- 자유 서술 응답은 현재 탭의 `sessionStorage`에 임시 보관되며 서버에 전송하지 않습니다. 브라우저 저장소에 민감한 내용을 남기지 않으려면 각 단계 하단의 기록 지우기를 사용하고 탭을 닫으세요. 검사 결과에서는 선택한 영역명만 같은 방식으로 전달됩니다.
- 이 시제품의 점수는 진단이나 치료 효과 판정용 절단점을 제시하지 않습니다. 공개 배포 전 문항 사용 권한, 원본 채점표, 임상 문구를 검토하세요.
